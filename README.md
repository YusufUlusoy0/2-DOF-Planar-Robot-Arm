# 2-DOF-Planar-Robot-Arm
MG90S servo motorlar ve Arduino kullanılarak geliştirilmiş, ters kinematik (inverse kinematics) hesaplamalarıyla belirli koordinatlara hareket edebilen 2 eksenli robot kolu projesi.

<img width="1080" height="1561" alt="WhatsApp Image 2026-04-28 at 20 37 32" src="https://github.com/user-attachments/assets/2e8868e4-59f0-4b47-bc3f-77ef874d5fad" />

Key Features:

    Hardware: Arduino Uno/Nano, 2x MG90S Servos.

    Calculations: Inverse kinematics implementation for precise positioning.

    3D Design: Custom parts designed in SolidWorks and 3D printed


How to Use:

    3D Models klasöründeki parçaları 3D yazıcıdan basın.

    Devreyi şemaya göre kurun.

    Kod klasöründeki kodu Arduino'ya yükleyin.
